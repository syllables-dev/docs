---
title: Errors
description: Error codes and response handling
---

Media API errors generally come back as an `errors` array. Check `code` for the specific failure; the HTTP status alone does not distinguish invalid parameters, credentials, and missing resources. Authentication can also fail with an empty 401 response body.

```json
{
  "errors": [
    {
      "id": "IT5VQ2GJTAE3JWS2RE2UD5FKXE",
      "title": "Invalid Parameter Value",
      "detail": "Value must be an integer less than or equal to 300, but was: 301",
      "status": "400",
      "code": "40005",
      "source": { "parameter": "limit" }
    }
  ]
}
```

`source.parameter` names the offending parameter when one is at fault, which makes most 400s self-diagnosing. `id` matches the `x-apple-jingle-correlation-key` response header.

## Codes

| Code | Status | Title | When |
| --- | --- | --- | --- |
| `40000` | 400 | Bad Request | A constraint spanning several parameters failed, such as needing one of `ids`, `name` or `genre`. |
| `40003` | 400 | Missing Parameter | A required parameter was absent. `source.parameter` names it. |
| `40004` | 400 | Invalid Parameter | The parameter name is not allowed on this endpoint. |
| `40005` | 400 | Invalid Parameter Value | The name is valid, the value is not. |
| `40008` | 400 | Invalid Path Value | A path segment does not resolve: an unknown resource type, relationship or view. |
| `40009` | 400 | Unknown Storefront | The storefront code does not exist. |
| `40013` | 400 | Invalid Request Signature | The user token lacks the signature data the social graph requires. |
| `40300` | 403 | Forbidden | Authentication required. |
| `40301` | 403 | Invalid Music User Token | The music user token is absent or invalid. |
| `40303` | 403 | Not specified | Returned in the body by `/v1/play/assets` when the account has no subscription. |
| `40400` | 404 | Resource Not Found | No resource with that id. |
| `40401` | 404 | Path Not Found | The API does not route that path at all. |
| `40403` | 404 | No related resources | The relationship name resolves but has nothing to return. |
| `50000` | 500 | Internal Service Error | Server-side failure. |

An unknown relationship returns `40008`; an existing relationship with nothing to return normally returns `40403`. Endpoint descriptions document exceptions, including subscription requirements and errors returned inside successful HTTP responses.
