This reference documents the private HTTP API used by Apple Music's web player at `amp-api.music.apple.com`. It covers endpoint parameters and response fields identified in the web client and checked against live requests.

Syllables maintains this reference to help developers work with an otherwise undocumented API. We make every effort to verify the details, but the documentation may contain errors or omissions. Use it as a starting point and check the behavior your application depends on.

Each endpoint page lists its parameters with the values the web player actually sends, rather than a prose summary. Where a value came from a request builder in the client, it is recorded as such; where an endpoint was found by probing the live API instead, the page says so.

Two limits are worth knowing before you rely on this:

- **The listed values are not a closed set.** The API drops an unrecognised entry in `extend` or `views` and still answers 200, so a value missing from a page is not proof the server rejects it.
- **This is a private API.** Apple can change it without notice, and nothing here is a stability guarantee. For the supported, documented API, use [Apple's own MusicKit reference](https://developer.apple.com/documentation/applemusicapi/).

Found something out of date or missing? [Contributing](../home/contributing/index.mdx) explains how to send it in.

<Callout title="API host">
These endpoints use the web player's credentials. Developer tokens issued for `api.music.apple.com` are not interchangeable with tokens for this host.
</Callout>

## A first request

Send a developer token with the `Origin` and `Referer` headers. The API checks the origin against the token scope; a missing or invalid origin returns 401.

```http
GET /v1/catalog/us/songs/1752214923?l=en-US&platform=web HTTP/1.1
Host: amp-api.music.apple.com
Authorization: Bearer <developer token>
Origin: https://music.apple.com
Referer: https://music.apple.com/
```

```json
{
  "data": [
    {
      "id": "1752214923",
      "type": "songs",
      "href": "/v1/catalog/us/songs/1752214923",
      "attributes": {
        "name": "Espresso",
        "artistName": "Sabrina Carpenter",
        "durationInMillis": 175459
      }
    }
  ]
}
```

`data` is always an array, even for a single resource. [Authentication](/musickit/authentication#origin-is-part-of-the-credential) covers the origin check, and [Request conventions](/musickit/conventions) covers the rest: query parameters, resource maps, pagination, and caching.
