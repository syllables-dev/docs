Vault is a TTML lyrics contribution platform. This section is the starting point for learning about Vault, working with lyric files, and contributing.

## Start with lyric files

- [Lyrics guidelines](./lyrics-guidelines/index.mdx): Writing, punctuation, capitalization, and line breaks for each language.
- [TTML](./ttml/index.mdx): Document structure, timing, vocal agents, alignment, and backing-vocal sublines.

To suggest changes to these docs or contribute to a project, see [Contributing](../home/contributing/index.mdx).
