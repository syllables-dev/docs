唱什么字就转写什么字。本页讲解哪些字应写入文件；行内排版参见[空格](./spacing.mdx)与[标点](./punctuation.mdx)。

本页规则同样适用于普通话与粤语。两者若有差异，仅在于歌词选用的字本身，行内的书写方式并无不同。

## 提交繁体中文

所有中文歌词一律以繁体字提交，普通话和粤语都不例外，无论发行版本使用简体字还是繁体字。服务端根据提交的繁体歌词生成简体版本，供使用简体字的读者查看。直接提交简体字会丢失繁体字之间的区别，服务端无法可靠地还原。

要求提交繁体字，是因为这个方向保留的信息多得多。繁体转简体大多是多对一，会丢失信息但无需人工判断；简体转繁体则是一对多，转换程序只能靠猜测来推断原词：

```text
发 -> 髮 or 發
干 -> 乾, 幹, or 干
面 -> 麵 or 面
后 -> 後 or 后
里 -> 裡 or 里
```

选错字就会改变原词。因此，应根据整行歌词的意思人工判断，不能完全依赖自动转换。

全曲统一使用繁体字，不要中途混入简体字。从其他来源转写的段落也应遵循这一规则。

  incorrectLabel="避免"

慶幸的是我 一直沒回頭`}

发行版本使用简体字时，应逐行转换并检查。自动转换的结果也必须核对，不能未经检查就直接提交。

## 简体版本的生成方式

繁简两种字形并非互为标签的关系。简化过程把若干繁体字合并为同一个简体字，且合并方式并不统一，因此两个方向的转换并不对称。

多数情况是多个繁体字对应一个简体字。这个方向会丢失信息，但无需判断，因为每个字只有一种结果。

```text
髮, 發  ->  发
後, 后  ->  后
裡, 裏  ->  里
```

少数字则相反：一个繁体字对应两个简体字，具体用哪一个由它所在的词决定。

### 由词决定的字

共有八个字属于这种情况。左侧为常见结果，右侧为例外。

```text
著   愛著你 -> 爱着你      原著 -> 原著
乾   乾燥   -> 干燥        乾坤 -> 乾坤
瞭   瞭解   -> 了解        瞭望 -> 瞭望
覆   答覆   -> 答复        覆蓋 -> 覆盖
藉   藉口   -> 借口        慰藉 -> 慰藉
於   於是   -> 于是        於戲 -> 於戏
徵   徵求   -> 征求        宮商角徵羽 -> 宫商角徵羽
彷   彷彿   -> 仿佛        彷徨 -> 彷徨
```

`著` 是歌词中最常出现的一个，因为它承担了两个互不相关的词。`愛著你`、`笑著` 中的 `著` 表示动作持续，简体作 `着`；`著作`、`原著` 表示著述，简体仍作 `著`。台湾用字习惯两者都写作 `著`，因此从台湾歌词看不出区别；香港用字习惯把前者写作 `着`，两者有别。

<AppleMusicQuote region="hk" songId="1444037351" quote={"有著我便有著你"} />

这一行用的是表示动作持续的那一个，故简体作 `有着我便有着你`。这首歌由香港发行，却采用台湾写法，而这正是常见情况。

### 转换的处理方式

转换以词为单位，而非逐字替换，因为单独一个 `著` 并无正确答案，须由所在的词决定。上述八个字各有一个默认结果，以及一份保留另一种写法的词表。

转换全部由程序自动完成，但并非万无一失。若发现简体版本中有错字，请反馈该行，不要改动提交的繁体歌词：文件保存的是繁体原文，需要修正的是生成环节。

### 对提交内容的影响

书写方式不变。按官方歌词的用字以繁体提交，上述八个字照原样写即可。不要为了配合转换而在 `著` 与 `着` 之间做选择，也不要自行转换为简体。

## 忠于原唱用词

除统一使用繁体字外，应保留发行歌词的用词、语体和异体字写法，以创作者认可的歌词为准。

### 异体字保持通篇一致

部分汉字有两种通行的繁体写法。两种写法都可以，按官方歌词选用，并在全曲中保持一致。

```text
裡 / 裏
什 / 甚
麼 / 麽
為 / 爲
```

不要只改动某一行的异体字写法。后面的段落参考了其他来源，也应与前文保持一致。

发行版本使用简体字时，往往无法判断原本采用哪种异体字，因为这些写法在简体中通常对应同一个字。转换时选定一种写法，后续出现该字时一律保持一致。

`著` 与 `着` 看似也属于这一组，实则不是：它们是两个字，而非同一个字的两种写法，详见[由词决定的字](#由词决定的字)。

### 粤语歌词按原样转写

多数粤语流行歌曲采用通用的书面中文填词，写在纸上与普通话无异，唱出来则是粤语。另有部分歌曲采用口语化粤语入词，使用 `唔`、`係`、`嘅`、`咁`、`乜嘢`、`冇` 等粤语字。

两种写法都可以。歌曲采用哪一种就保留哪一种，不要相互改写。

口语化粤语，按原样保留：

  songId="1442332083"
  quote={"我唔知道 點解你要咁對我"}
/>

<AppleMusicQuote
  region="hk"
  songId="1444176947"
  quote={"咪話冇乜所謂"}
/>

粤语录音中的通用书面语，同样按原样保留：

<AppleMusicQuote
  region="hk"
  songId="892682436"
  quote={"風繼續吹 不忍遠離"}
/>

不要因为 `是` 看起来更正式就把 `係` 改成 `是`，也不要因为这是一首粤语歌就把 `是` 改写成 `係`。两者的读音和拼音不同，换字就会改变歌词所记录的发音。参见[粤语拼音转写](../../romanization/cantonese.mdx)。

### 尊重歌词中的人称代词写法

中文书面语中存在读音相同、字形不同的人称代词。`你` 与 `妳` 都读 *nǐ*，`他`、`她`、`牠` 都读 *tā*。不同字形表示不同的指代，应按原词保留，不能一律改成常见写法。

<AppleMusicQuote region="tw" songId="160857031" quote={"妳還在想著他嗎"} />

这行歌词中使用 `妳` 指代被倾诉的女性，用 `他` 指代她心中所想的男性。若将两者都统写为默认的 `你` 与 `他`，就会丢掉词作者原有的指代区分。

除歌词有意切换以外，全曲内部的人称代词选择应保持一致。

## 完整写出重复字

唱出的每一次重复都要完整写出。不要将重复的字归纳为次数标记，也不要用连字符或顿号连接重复字。重复唱出的字直接连写。

<CodeComparison
  correctLabel="推荐"
  incorrectLabel="避免"
  correct={"我我我我也也 已經是個糟老頭"}
  incorrect={`我、我、我、我、也、也 已經是個糟老頭
我-我-我-我也-也 已經是個糟老頭`}
  source={{ region: "tw", songId: "657693184" }}
/>

<AppleMusicQuote
  region="tw"
  songId="657693184"
  quote={"時光匆匆匆匆流走 也也也不回頭"}
/>

第二行中 `匆匆` 作为叠词重复了一遍，`也` 则单独连唱了三次。两处都是实际唱出的内容，均须全部写出。关于重复字的时间轴切分方式，参见[重复字的处理](./splits.mdx#重复字的处理)。

## 伴唱与和声

### 逐行同步歌词

仅在制作逐行同步歌词时，将简短的伴唱乐句用半角括号括起，置于对应的主唱行末尾，遵循 [Apple Music for Artists 规范](https://artists.apple.com/support/1111-lyrics-guidelines)。括号内侧不留空格，括号外侧与前面的主唱文本空一格。

<AppleMusicQuote
  region="tw"
  songId="1078561855"
  quote={"一波還未平息 (一波還未平息 一波又來侵襲)"}
/>

### 逐词同步歌词

将伴唱乐句独立成子行，置于对应的主唱行下方。子行保留自己的用词、行内空格与括号，与主唱重叠时也单独处理。

<AppleMusicQuote
  region="tw"
  songId="1078561855"
  quote={`一波還未平息
(一波還未平息 一波又來侵襲)`}
/>

关于伴唱子行的文件结构，参见 [TTML 中的伴唱和声](../../../ttml/background-vocals.mdx)。

主唱本人唱出的即兴插入句（Ad-lib）留在主唱文本中。延迟尾音或混响余韵是后期制作对主唱的重复，并非第二位演唱者，无需单列子行。

## 没有词义的人声

哼唱、语气词这类没有词义的声音，只要构成了旋律、记忆点（Hook）或有意义的应答，就要转写。使用对应读音的汉字记录。

```text
啦   哦   喔   噢
嗚   啊   呀   哎
哈   呵   哼   嘿
```

<AppleMusicQuote
  region="tw"
  songId="657693184"
  quote={"啦啦啦啦 啦啦啦啦 啦啦啦啦啦啦"}
/>

这类人声如果采用拉丁字母写法，就保留原样。`Oh`、`Ooh`、`Whoa`、`Ah` 与 `La-la-la` 在普通话与粤语录音中都很常见，遵循[英文人声拼写规则](../english/text.mdx#没有词义的人声)，包括连接连贯发音的连字符与分隔独立呼应的逗号。

不要用重复汉字来表现拖长的尾音，也不要转写每一处细碎的气息。经后期处理后只作为背景音色、不再构成词句的人声，不必转写。

## 念白段落

清晰可辨的念白与对话插段均须转写。口语化粤语在念白中出现的频率远高于歌乐句落，因此通篇采用通用书面语的曲目，其对话中也可能带有 `唔`、`係`、`嘅`。如实记录听到的内容。

演唱者标签、段落标题与说明性文字一律不要写入歌词正文。关于文件内演唱角色的分配，参见 [TTML 中的演唱者与声部](../../../ttml/agents.mdx#spoken-passages)。

## 完整版与洁版

以当前转写的录音版本为准。能听清且未经消音的词应完整写出，只有录音遮蔽了词句时，歌词才作相应处理。某个词的全部或部分被提示音盖住或静音时，用星号替换整个词，不要保留其中一部分。

洁版录音中如果歌手唱了替代词，转写该替代词。不要擅自按完整版还原词句，也不要给录音中未做遮盖的内容额外添加审查标记。

## 排查形似字符

某些字符在 Unicode 中存在视觉上几乎完全一致的异码字，最常见的是康熙部首。`⼼`（U+2F3C）与 `心`（U+5FC3）在绝大多数字体中渲染出来的字形完全一样，但只有后者才是正规汉字。从 PDF 或图片附注中复制粘贴时，这种形似字很容易被带进来；字形显示虽然正常，却会破坏搜索、排序、拼音注音以及语音朗读。

<CodeComparison
  correctLabel="推荐"
  incorrectLabel="避免"
  correct={"我發覺心裡有條裂痕"}
  incorrect={"我發覺⼼裡有條裂痕"}
  source={{ region: "hk", songId: "1879436477" }}
/>

这两行仅在第三个字上有差异。

转写中文时请使用标准输入法键入，不要直接从图片附注等不可靠来源复制字形，交付前务必检查文件。空格也存在类似的问题，参见[使用普通空格，排查形似字符](./spacing.mdx#使用普通空格排查形似字符)。
