These guidelines cover the text of a contribution: the words as they are sung, the translations that sit beside them, and the romanizations that spell out how they sound. Structure and timestamps belong to the file rather than the text, and are covered in the [TTML guide](../ttml/index.mdx).

Conventions differ by language, so start with the guide for the language of the recording.

## Rules for every language

- Transcribe the exact version you are working from. A live performance, a clean edit, or an alternate recording may have different words.
- Keep the artist's wording. Correct transcription and spelling mistakes without rewriting the lyric.
- Write repeated words and repeated lines in full each time they are performed.
- Break lines at natural vocal phrases. A sentence may continue across several lines.
- Put each verse, chorus, and other distinct part of the song in its own section.
- Trust your ears. Published transcriptions, including Apple Music's, can be wrong.

## Translation

A translation carries the meaning of each line into another language. It rides along as a separate track keyed to the original lines, so the sung text stays exactly as it was written. See [Translations](../../packages/parse/lyrics-formats/ttml/translations.mdx) for how a file stores one.

## Romanization

A romanization writes the pronunciation of each line in the Latin alphabet, for listeners who do not read the original script. It is a separate track as well, and it does not replace the sung text. See [Transliterations](../../packages/parse/lyrics-formats/ttml/transliterations.mdx) for how a file stores one.
