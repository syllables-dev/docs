---
title: Agents and voices
description: Assign lyrics to the people performing them.
---

An agent identifies who sings or speaks a part. Declare each performer once in `<head><metadata>`, then use their ID on the lines they perform.

## Declare the voices

```xml
<ttm:agent xml:id="v1" type="person"/>
<ttm:agent xml:id="v2" type="person"/>
<ttm:agent xml:id="v1000" type="group"/>
<ttm:agent xml:id="v2000" type="other"/>
```

Use `v1`, `v2`, and so on for individual performers, `v1000` for people performing together, and `v2000` for other voices, such as a speaker outside the main and featured artists. Keep the same ID whenever a performer returns. An artist who switches from singing to speaking still uses their existing agent.

Declare only the voices the file uses. The player counts the declared types when it lays out the song, so an agent that no line references still affects the result.

These declarations belong inside the metadata in the [example document](./index.mdx#read-a-lyrics-document).

## Assign the lines

```xml
<p begin="10.000" end="12.000" ttm:agent="v1">Hello world</p>
<p begin="12.000" end="14.000" ttm:agent="v2">Hello again</p>
<p begin="14.000" end="16.000" ttm:agent="v1000">All together</p>
```

The first two lines belong to different singers. The third is performed together. The text here is invented to demonstrate the markup.

## How voices affect alignment

In a left-to-right side-aligned view, the first person starts on the left and a change of person switches sides. Group parts use the left side; other voices use the right. The declared type controls this behavior, not the number in the ID. Right-to-left text reverses the sides, and the player's layout can override them.

Alignment is derived, not designed. Tag each line with the performer who sings it and let the player work out the sides. Do not hand a duet part to `v2000`, and do not swap performer IDs, because it puts a line on the side you had in mind. That records the wrong singer, and the layout still changes with the player, the reading direction, and the rest of the song.

See [Agents and singers](../../packages/parse/lyrics-formats/ttml/agents.mdx#alignment) for the full alignment rules, an example sequence, and assignments within a line.

## Spoken passages

A spoken part is performed by someone, so it takes an agent like any other line. A performer who stops singing and starts speaking keeps the agent they already have. Use `v2000` only for a voice outside the main and featured artists, such as a narrator or an interviewer.

The file records who speaks the words. It does not mark the delivery as speech, and no agent type means "spoken".

## Backing vocals

A singer or group can perform either lead or backing vocals. Keep the agent assignment and the vocal part separate: `type="group"` does not mark a backing part. Use [a backing span](./background-vocals.mdx) for that.

A backing part can also name its own performer. Put `ttm:agent` on the backing span when someone other than the line's agent sings it.
