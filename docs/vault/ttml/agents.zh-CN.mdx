---
title: 演唱者与声部
description: 将歌词分配给对应的演唱与念白人员
---

演唱者标签（Agent）用于指明特定歌词行是由谁演唱或念白的。在 `<head><metadata>` 中为每位表演者声明一次，随后在他们演唱的歌词行上引用对应的 ID。

## 声明演唱者

```xml
<ttm:agent xml:id="v1" type="person"/>
<ttm:agent xml:id="v2" type="person"/>
<ttm:agent xml:id="v1000" type="group"/>
<ttm:agent xml:id="v2000" type="other"/>
```

使用 `v1`、`v2` 等表示个人演唱者，`v1000` 表示多人合唱，`v2000` 则表示其他声部（例如领衔歌手与特邀歌手之外的念白者）。同一位表演者再次出场时，始终保持相同的 ID。歌手由演唱转为说白时，依然沿用原有的 ID。

仅在文件中声明实际用到的演唱者。播放器在排版歌词时会统计已声明的类型，即便某个 agent 未被任何行引用，依然会影响最终的排版效果。

这些声明属于[示例文档](./index.mdx#读懂歌词文档)内的元数据。

## 为歌词行分配演唱者

```xml
<p begin="10.000" end="12.000" ttm:agent="v1">Hello world</p>
<p begin="12.000" end="14.000" ttm:agent="v2">Hello again</p>
<p begin="14.000" end="16.000" ttm:agent="v1000">All together</p>
```

前两行分属不同的歌手，第三行则是众人合唱。示例中的文本为虚构内容，仅供演示标签结构。

## 声部对歌词排版对齐的影响

在双侧对齐视图中，第一位出场的歌手歌词居左，当换人演唱时两侧交替。合唱部分默认居左显示，其他声部（other）则居右显示。决定这一对齐行为的是声明中的 `type` 属性，而非 ID 中的数字大小。从右向左阅读的语言则反转对齐方向，且不同播放器的自身排版策略也可能覆盖上述规则。

对齐方向是播放器自动推导出来的，而非人工硬编码指定的。只需如实为每行歌词标记对应的演唱者，排版对齐交给播放器处理。不要为了让某行歌词显示在你期望的一侧而把对唱分给 `v2000`，更不要随意互换演唱者 ID。这样做不仅记录了错误的演唱者信息，而且一旦播放器、阅读方向或歌曲其他段落发生变化，排版依然会走样。

完整的对齐规则、排版示例以及行内声部划分，参见[演唱者与歌手](../../packages/parse/lyrics-formats/ttml/agents.mdx#alignment)。

## 念白

念白同样是由特定人员表演的，因此与其他歌词行一样需要分配 agent。歌手从唱歌切换为说白时，保持其已有的 agent ID。仅当念白来自领衔歌手与特邀嘉宾之外的第三方（如旁白或采访者）时，才使用 `v2000`。

文件仅记录具体是谁说出这段话。文件本身不标记演绎方式是否为口语，也没有任何特定的 agent 类型用来代表「念白」。

## 伴唱和声

歌手或合唱团既可以演唱主唱，也可以演唱伴唱。演唱者分配与声部角色是两回事：`type="group"` 并不能代表伴唱声部。标记伴唱声部应使用[伴唱 span 标签](./background-vocals.mdx)。

伴唱声部也可以指定独立的演唱者。如果伴唱并非由该主唱行的歌手演唱，在伴唱 span 上添加 `ttm:agent` 属性；若伴唱就是由主唱本人合唱录制的，则省略该属性。
