---
title: Timing
description: Apply timestamps to lyric lines, words, and syllables
---

Timing connects lyric text to the recording. Line timing says when a whole line is performed. Word timing adds intervals inside that line so the player can follow individual words or syllables.

Always time lyrics against the exact recording they accompany. A different edit, introduction, or performance shifts the timing even when the words are unchanged.

## Read timestamps

A timestamp is a clock value written as minutes, seconds, and an optional fraction of a second with up to three decimal places.

```text
10.000
00:10.000
01:23.450
```

These represent ten seconds, ten seconds, and one minute and 23.45 seconds.

Do not add a third component for hours. The player reads the last component as seconds and the one before it as minutes, so `01:02:03` becomes 123 seconds rather than one hour.

Use `begin` for the start of an interval and `end` for its end. The end value is a timestamp, not a duration added to the start.

## Line timing

Put the line's timing on its `<p>` element:

```xml
<p begin="00:10.000" end="00:12.000">I left my coat</p>
```

This describes one interval for the entire line. It does not tell the player when each word starts.

## Word and syllable timing

Keep the line's timing on `<p>` and add timed `<span>` elements inside it:

```xml
<p begin="00:10.000" end="00:12.000">
  <span begin="00:10.000" end="00:10.300">I </span>
  <span begin="00:10.300" end="00:10.700">left </span>
  <span begin="00:10.700" end="00:11.000">my </span>
  <span begin="00:11.000" end="00:12.000">coat</span>
</p>
```

Each word now has its own interval, and each span carries the space that follows its word. Keep that space inside the span. Indentation and line breaks between the spans are formatting, and a tool that reformats the file discards them, which would run the words together.

A span does not have to contain a whole word. To time syllables separately, split the word into adjacent spans without inserting spaces or visible hyphens:

```xml
<p begin="00:10.000" end="00:12.000">
  <span begin="00:10.000" end="00:10.700">Beau</span><span begin="00:10.700" end="00:11.200">ti</span><span begin="00:11.200" end="00:12.000">ful</span>
</p>
```

The displayed word remains:

```text
Beautiful
```

Use the sung pronunciation to determine syllable boundaries. A syllable held over several notes does not become several written syllables.

Setting the document's `itunes:timing` attribute to `Word` does not create word timing on its own. The timed spans inside each line are what the player follows.

## Keep intervals consistent

- Give each timed element both a start and an end.
- Set the start before the end.
- Keep a word's interval inside its line, and a line's interval inside its section.
- Extend a line's end to cover a backing subline that continues past the lead.
- Keep all timestamps within the recording's duration.
- Preserve real pauses and vocal overlaps. Do not stretch every word until the next word begins just to fill a gap.

Timing describes the performance. It does not replace the editorial decision about where a lyric line should break.
