---
title: Numeric
description: Faithful SwiftUI numeric text on the web.
---

`@syllables-dev/numeric` animates text the way SwiftUI's `.contentTransition(.numericText())` does. Glyphs that change blur, shrink, and slide out while their replacements slide in, and the text reflows on a spring as its width changes. Glyphs that stay the same never move.

```tsx
import { NumericText } from "@syllables-dev/numeric/react";

export const Seconds = ({ seconds }: { seconds: number }) => (
  <NumericText countsDown value={`${seconds} sec`} />
);
```

It works with React, Vue, Svelte, or plain DOM, and has no dependencies.
