Every tool we build for Syllables starts as something we needed ourselves. When it turns out to be useful beyond our own work, we release it to the public as a package.

## Why we publish them

Lyrics are harder to get right than they look. Formats are scattered across apps and services, most are half documented, and small mistakes in timing or text are easy to miss. Every project that touches lyrics ends up solving the same problems from scratch, and most solve them only partly.

We would rather solve them once, carefully, and share the result. A package you can install saves you that work. It also gives open source projects a common base to build on, so fixes made in one place reach everyone who depends on it.

## What we are working toward

We want a better lyrics experience for everyone who listens to music, not only for people using one app. To us that means:

- **Accurate timing**, down to the syllable, so lyrics follow the voice instead of drifting ahead or behind.
- **Faithful text** that matches what is actually sung, in every language and script.
- **Lyrics that travel**, moving between formats and apps without losing timing, vocals, or translations on the way.
- **Interfaces that feel right**, with motion and typography that respect the music they sit next to.

No single app can deliver all of that alone. Shared tools are how the whole ecosystem gets better together.

## Help us

These packages grow with the people using them. If something is missing, wrong, or harder than it should be, we want to hear about it. [Contributing](/contributing) explains how to report a problem or propose a change.
