## 安装

```package-install
@syllables-dev/hanzi
```

开发包提供 ES 模块和 TypeScript 类型声明。

## 转换文本

按转换方向导入对应的函数，传入字符串即可。

```ts
import { toHans } from "@syllables-dev/hanzi/hans";
import { toHant } from "@syllables-dev/hanzi/hant";

toHant("我们回家吧"); // "我們回家吧"
toHans("我們回家吧"); // "我们回家吧"
```

## 检测简繁

`detect` 返回文本是简体还是繁体，可以用来判断是否需要转换。

```ts
import { detect } from "@syllables-dev/hanzi/detect";

detect("我们回家吧"); // "hans"
detect("我們回家吧"); // "hant"
```
