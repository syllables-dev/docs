## 按行转换

每个函数都可以传入一个字符串或一组行，返回值的形式与传入的相同。字符串里有换行时会逐行转换，换行符原样保留。

```ts
toHant(["以后见", "干杯"]); // ["以後見", "乾杯"]
toHant("第一行\r\n第二行"); // "第一行\r\n第二行"
```

转换歌词时，建议每首歌传入一个数组，一行一项，这样每一行都会单独判断。

## 一个简体字对应几个繁体字

不少简体字对应不止一个繁体字。Hanzi 会根据所在的词，选出这个词需要的那一个。

```ts
toHant(["头发", "出发"]); // ["頭髮", "出發"]
toHant(["尽快", "尽力"]); // ["儘快", "盡力"]
```

## 只换字形，不改用词

转换只改变每个字的写法。各地说法不同的词保持原样，所以输出的字数总是和输入一样。

```ts
toHant("软件和视频"); // "軟件和視頻"，不会变成 "軟體和影片"
```

## 香港字形

繁体输出采用香港字形。同一个意思在香港有两种写法时，统一用更通行的现代写法。

```ts
toHant("线着说里面"); // "綫着説裏面"
toHant(["台湾", "香烟", "了解"]); // ["台灣", "香煙", "了解"]
```

转换成简体时，「著」保持不变。

```ts
toHans("笑著哭"); // "笑著哭"
```

## 粤语

用粤语口语写的句子，会按粤语的习惯转换。只有粤语才用的字，两个方向都保持原样。

```ts
toHant(["梗系上集好睇", "我哋嗰只猫"]); // ["梗係上集好睇", "我哋嗰隻貓"]
toHans(["嗰阵时", "攞晒"]); // ["嗰阵时", "攞晒"]
```

## 本来就是目标写法的行

一行文字如果已经是要转换成的写法，内容会保持不变。只有另一种写法的字会被转换；简繁通用的字，只在所在的词明确需要时才会改。

```ts
toHant(["皇后與國王们", "我們心里"]); // ["皇后與國王們", "我們心裏"]
```

## 判断繁简

`detect` 返回以下四个值之一。

| 值 | 含义 |
| --- | --- |
| `"hans"` | 简体 |
| `"hant"` | 繁体 |
| `"both"` | 是中文，但没有能区分繁简的字 |
| `"none"` | 没有汉字 |

```ts
detect(["我们回家吧", "我們回家吧", "人山人海", "Hello"]);
// ["hans", "hant", "both", "none"]
```

结果为 `"both"` 的文字，通常不用转换，简体和繁体读者都能直接看懂。
