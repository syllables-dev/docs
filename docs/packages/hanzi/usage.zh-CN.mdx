## 按行转换

所有函数都接受字符串或字符串数组，返回相同的类型。多行字符串会逐行转换，换行符保持不变。

```ts
toHant(["以后见", "干杯"]); // ["以後見", "乾杯"]
toHant("第一行\r\n第二行"); // "第一行\r\n第二行"
```

转换歌词时，建议每首歌传入一个数组，每行一项，这样每行都会单独检测。

## 一简对多繁

很多简体字对应多个繁体字，Hanzi 会根据所在的词选择正确的繁体字。

```ts
toHant(["头发", "出发"]); // ["頭髮", "出發"]
toHant(["尽快", "尽力"]); // ["儘快", "盡力"]
```

## 只转字形，不换词汇

转换只改变字形。两岸三地用法不同的词汇保持原样，所以输出和输入的字数始终一致。

```ts
toHant("软件和视频"); // "軟件和視頻"，不会变成 "軟體和影片"
```

## 香港字形

繁体输出使用香港字形。同一个字在香港有两种常见写法时，统一使用更通行的写法。

```ts
toHant("线着说里面"); // "綫着説裏面"
toHant(["台湾", "香烟", "了解"]); // ["台灣", "香煙", "了解"]
```

转换成简体时，「著」保持不变。

```ts
toHans("笑著哭"); // "笑著哭"
```

## 粤语

粤语口语的句子会按粤语用字转换。粤语专用字在两个方向都保持不变。

```ts
toHant(["梗系上集好睇", "我哋嗰只猫"]); // ["梗係上集好睇", "我哋嗰隻貓"]
toHans(["嗰阵时", "攞晒"]); // ["嗰阵时", "攞晒"]
```

## 已经是目标写法的文本

如果一行已经是目标写法，内容保持不变，只转换混在其中的另一种写法的字。简繁通用的字，只有在词语明确需要时才会修改。

```ts
toHant(["皇后與國王们", "我們心里"]); // ["皇后與國王們", "我們心裏"]
```

## 检测简繁

`detect` 返回以下四个值之一。

| 值 | 含义 |
| --- | --- |
| `"hans"` | 简体 |
| `"hant"` | 繁体 |
| `"both"` | 是中文，但没有能区分繁简的字 |
| `"none"` | 没有汉字 |

```ts
detect(["我们回家吧", "我們回家吧", "人山人海", "Hello"]);
// ["hans", "hant", "both", "none"]
```

返回 `"both"` 的文本一般不需要转换。
