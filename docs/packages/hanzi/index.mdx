---
title: Hanzi
description: Convert between Simplified and Traditional Chinese, and tell which one a line is in.
---

`@syllables-dev/hanzi` converts Chinese text between Simplified and Traditional script and detects which script a line is written in. Traditional follows Hong Kong usage.

```ts
import { toHant } from "@syllables-dev/hanzi/hant";

toHant("头发很长"); // "頭髮很長"
toHant("出发"); // "出發"
```

It converts characters, never vocabulary, so the words stay the writer's own. It has no dependencies and runs anywhere JavaScript does, including Cloudflare Workers.
