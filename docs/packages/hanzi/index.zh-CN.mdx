`@syllables-dev/hanzi` 是一个简繁转换库，也可以检测文本是简体还是繁体。繁体按香港用字习惯输出。

```ts
import { toHant } from "@syllables-dev/hanzi/hant";

toHant("头发很长"); // "頭髮很長"
toHant("出发"); // "出發"
```

只转换字形，不替换词汇。零依赖，可以在任意 JavaScript 运行时中使用，包括 Cloudflare Workers。
