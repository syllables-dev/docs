## 入口

每个函数也可以从单独的入口导入。

| 导入路径 | 导出内容 |
| --- | --- |
| `@syllables-dev/hanzi` | `convert`、`toHant`、`toHans`、`detect`、`Script`、`Target` |
| `@syllables-dev/hanzi/hant` | `toHant` |
| `@syllables-dev/hanzi/hans` | `toHans` |
| `@syllables-dev/hanzi/detect` | `detect`、`Script` |

## 函数

所有函数都接受字符串或字符串数组，返回相同的类型。

| 函数 | 返回值 | 说明 |
| --- | --- | --- |
| `toHant(text)` | `string` 或 `string[]` | 转换为繁体中文，使用香港字形。 |
| `toHans(text)` | `string` 或 `string[]` | 转换为简体中文。 |
| `convert(text, target)` | `string` 或 `string[]` | 按 `target` 转换，等同于调用 `toHant` 或 `toHans`。 |
| `detect(text)` | `Script` 或 `Script[]` | 检测每行是简体还是繁体。 |

```ts
function toHant(text: string): string;
function toHant(lines: readonly string[]): string[];

function toHans(text: string): string;
function toHans(lines: readonly string[]): string[];

function convert(text: string, target: Target): string;
function convert(lines: readonly string[], target: Target): string[];

function detect(text: string): Script;
function detect(lines: readonly string[]): Script[];
```

转换前后字数始终一致。英文、数字、标点、emoji 等非中文内容原样保留。

## 类型

```ts
type Target = "hans" | "hant";

type Script = "hans" | "hant" | "both" | "none";
```

`Script` 各个值的含义见[检测简繁](./usage.mdx#检测简繁)。
