## Detect and read

Identifies the format from the text and returns a [`FormatId`](#format-specific-entry-points), or `null` for unrecognized input. It checks recognizable syntax; it does not fully parse or validate the file.

## Write and convert

### write

Serializes a document with the chosen writer. The document is not mutated. Unsupported features throw unless an available lossy projection is explicitly enabled.

### convert

## Inspect format support

### losses

Returns the features in this document that would lose fidelity in the target format. This is a document-specific report, not a complete preflight check: an empty array does not guarantee that `write()` will succeed.

<auto-type-table path="../../../../node_modules/@syllables-dev/parse/dist/api.d.ts" type="{ losses: typeof losses }" name="lossesReference" />

The returned `ConversionLoss` values are:

| Value | Reported when |
| --- | --- |
| `agents` | The document attributes lines to agents and the target cannot record that attribution. |
| `backing` | The target cannot keep a separate backing track, so its words fold into the primary text. |
| `metadata.album` | The target cannot store an album, or cannot store this value as written. |
| `metadata.artist` | The target cannot store a primary artist, or cannot store this value as written. |
| `metadata.songwriters` | The target cannot store songwriters, or cannot store this list as written. Tag-based formats keep one name. |
| `metadata.title` | The target cannot store a title, or cannot store this value as written. |
| `pronunciations` | The target cannot store pronunciation tracks, or cannot keep this document's track metadata. |
| `translations` | The target cannot store translation tracks, or cannot keep this document's track metadata. |
| `lineRange` | The target cannot store these line boundaries. LRC infers each end from the next line's start. |
| `wordTiming` | The document is word-timed and the target writes line timing only. |

A metadata value is reported as written when the format stores the field but cannot carry line breaks or surrounding whitespace.

### capabilities

## Create and validate

### createDocument

Returns a new document with `version: 1`, `timing: "line"`, empty `agents` and `lines` arrays, and an empty `meta` object. Each call creates independent collections.

<auto-type-table path="../../../../node_modules/@syllables-dev/parse/dist/document.d.ts" type="{ createDocument: typeof createDocument }" name="createDocumentReference" />

### validate

Reports timing findings in document and track order without changing the document. Static documents return an empty array. Line order is based on start times; overlapping lines are not automatically invalid.

<auto-type-table path="../../../../node_modules/@syllables-dev/parse/dist/validate.d.ts" type="{ validate: typeof validate }" name="validateReference" />

Each finding has a stable `code`, the affected line or syllable's `id`, and a human-readable `message`. Use `code` for application logic and localization.

<auto-type-table path="../../../../node_modules/@syllables-dev/parse/dist/types.d.ts" name="Problem" />

| Code | Message |
| --- | --- |
| `line-out-of-order` | line starts before the preceding line |
| `line-invalid-time` | line times must be integer milliseconds |
| `line-invalid-range` | line must end after it begins |
| `syllable-out-of-order` | syllable starts before the preceding syllable |
| `syllable-invalid-time` | syllable times must be integer milliseconds |
| `syllable-invalid-range` | syllable ends before it begins |
| `syllable-outside-line` | syllable extends outside its line |

### ParseError

`ParseError` extends `Error` and has the name `"ParseError"`. Import it from the package root and use `instanceof ParseError` to distinguish unreadable input from other failures. Writer failures and invalid options can throw ordinary errors; see [error handling](./usage.mdx#handle-invalid-input).

## Format-specific entry points

These public imports each export `read`, `write`, and a `capabilities` object:

| Format ID | Import |
| --- | --- |
| `ttml` | `@syllables-dev/parse/ttml` |
| `lrc` | `@syllables-dev/parse/lrc` |
| `lyl` | `@syllables-dev/parse/lyl` |
| `eslrc` | `@syllables-dev/parse/eslrc` |
| `qrc` | `@syllables-dev/parse/qrc` |
| `yrc` | `@syllables-dev/parse/yrc` |
| `lys` | `@syllables-dev/parse/lys` |
| `lqe` | `@syllables-dev/parse/lqe` |

Their readers take `(text, options?)` and writers take `(doc, options?)`. There is no format argument to select the codec, and `capabilities` is an object rather than a function. Import shared types and `ParseError` from the root.

```ts
import { capabilities, read, write } from "@syllables-dev/parse/ttml";
import type { LyricsDocument } from "@syllables-dev/parse";

function rewrite(source: string): string {
  const doc: LyricsDocument = read(source);
  return write(doc);
}

console.log(capabilities.timing.word); // true
```
