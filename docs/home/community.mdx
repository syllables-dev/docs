Syllables welcomes lyric format examples, TTML work, API findings, and feedback from people building players or extensions.

## GitHub

Browse the repositories at [syllables-dev](https://github.com/syllables-dev) to follow development. For a problem with a particular package, use its repository and include the package version, steps to reproduce, and a small example of the behavior.

## Discord

Join the [Syllables Discord](https://discord.gg/9SqsURJ2mG) to ask questions, discuss lyric tooling, and share work in progress.

## Improve the documentation

For an unclear rule or a missing case in the lyrics guidelines, read [Contributing](./contributing/index.mdx). Include the page, the proposed change, and an example that explains why it helps.

Each article also has an **Open in GitHub** option near the title, which links to its source file.
