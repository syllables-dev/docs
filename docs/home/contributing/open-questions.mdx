---
title: Open questions and discussions
description: Ask questions and discuss ideas for Syllables.
---

Questions can uncover missing explanations or cases a guideline does not cover. Share the relevant page or project and a concrete example so others can follow the issue.

Use the relevant project's GitHub issues for a reproducible problem or a specific proposal. For exploratory questions or help finding the right project, join [Discord](https://discord.gg/9SqsURJ2mG).

Before opening a new discussion, check for an existing one on the same topic. Add new examples or findings there when they help move the discussion forward.
