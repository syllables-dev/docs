title: Contributing
description: Help improve Syllables documentation and projects.
---

Contributions can be a clearer explanation, a useful example, a bug report, or a code change. Start with the documentation or project the change belongs to.

## Documentation

For corrections to the docs, open an issue or propose a pull request in the documentation repository when it is accessible. Include the page and explain what needs changing. For wording fixes, show the suggested text; for a guideline change, include a concrete example and the reason behind it.

Keep lyric examples faithful to the recording. When translating a page, translate the explanation while preserving lyric text, code, and timing data.

See [Proposing changes](./proposing-changes.mdx) for help preparing a focused suggestion.

## Projects

Find the relevant repository under [syllables-dev on GitHub](https://github.com/syllables-dev) and read its contribution instructions. For a bug report, include the version, reproduction steps, and expected and actual behavior. Discuss larger changes before starting implementation so the approach can be agreed on.

## Questions and ideas

Use [Discord](https://discord.gg/9SqsURJ2mG) to ask where a contribution belongs or discuss an idea. If a repository is not accessible, share the page link or project name there with the proposed change.
