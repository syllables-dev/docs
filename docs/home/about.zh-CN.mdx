Syllables 开发歌词工具，也研究 Apple Music 的歌词格式与显示方式。相关工作涵盖歌词文件的编写、解析，以及播放器中的歌词渲染。

## 项目

[Vault](../vault/index.mdx) 是一个 TTML 歌词贡献平台，以社区贡献的歌词文件为核心。

Syllables 也开发面向歌词与音乐应用的工具和库，相关文档汇集在[开发包](../packages/index.mdx)分区。

## 研究与方向

除了开发工具，Syllables 也研究 Apple Music API 和歌词文件格式。后续计划包括统一的歌词标准，以及与其他音乐平台的集成。

[项目网站](https://syllables.dev/about) 介绍了更完整的方向。

## 关注进展

[社区](./community.mdx)页面整理了项目链接，以及分享研究发现、例子和反馈的渠道。
