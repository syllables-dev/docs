Syllables builds lyric tools and researches how Apple Music represents and displays lyrics. These docs bring together the writing conventions, file formats, and package documentation behind that work.

## Start here

If you're preparing lyrics, start with the guide for the language of the recording. For file structure and timing, head to TTML.

## What's in the docs

### Vault

[Vault](../vault/index.mdx) is a TTML lyrics contribution platform. This section is the home for learning about Vault, working with lyric files, and contributing. Start with the guidelines for writing conventions or the TTML guide for file structure and timing.

### Packages

[Packages](../packages/index.mdx) is the home for Syllables developer tools and libraries. Browse by package for setup instructions, usage guides, and API references when building lyrics and music applications.

## Find your way around

Use the sidebar to switch between different pages. Expand a category to browse its pages, or use search to find a topic directly. On mobile, open the sidebar with the menu button.

Within an article, **On this page** lists its headings. The links at the bottom move to the previous or next page in the section. Use the language selector to switch between English and Simplified Chinese; pages without a translation display the English content.

## Get involved

Found an unclear rule or a missing example? Start with [Contributing](./contributing/index.mdx). For the project's direction and planned work, read [About Syllables](./about.mdx). Follow development on [GitHub](https://github.com/syllables-dev) or join the discussion on [Discord](https://discord.gg/9SqsURJ2mG).
