整理歌词时，先查阅录音所用语言的编写规范。需要了解文件结构和时间标记时，再阅读 TTML 指南。

## 文档包含什么

### Vault

[Vault](../vault/index.mdx) 是一个 TTML 歌词贡献平台。了解 Vault、处理歌词文件和参与贡献，都可以从这个分区开始。编写歌词时可先查阅歌词规范，文件结构和时间标记则参见 TTML 指南。

### 开发包

[开发包](../packages/index.mdx) 是 Syllables 开发工具与库的文档入口。构建歌词或音乐应用时，可以按开发包查找安装说明、使用指南和 API 参考。

## 如何查找内容

通过侧边栏可以切换不同页面。展开分类即可浏览其中的页面，也可以用搜索直接查找主题。在手机上，点击菜单按钮打开侧边栏。

文章内的「本页内容」列出各节标题，页底的链接可以前往同一分区的上一页或下一页。语言菜单可切换英文与简体中文；尚未翻译的页面会显示英文内容。
