歌词格式的例子、TTML 相关工作、API 研究发现，以及播放器或扩展开发中的反馈，都欢迎在社区分享。

## GitHub

在 [syllables-dev](https://github.com/syllables-dev) 可以浏览项目仓库、关注开发进展。反馈某个开发包的问题时，请到对应仓库说明版本、复现步骤，并附上能展示问题的简短例子。

## Discord

加入 [Syllables Discord](https://discord.gg/9SqsURJ2mG)，可以提问、讨论歌词工具，也可以分享正在进行的工作。

## 完善文档

歌词规范中有不够清楚的规则或遗漏的情况，可以参照[贡献指南](./contributing/index.zh-CN.mdx)提出建议。请附上相关页面、建议修改的内容，以及能说明理由的例子。

每篇文章标题附近的「在 GitHub 中打开」选项可以前往对应的源文件。
